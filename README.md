Designed for developers, designers, freelancers, and creative professionals who want a professional online presence and a portfolio that works smoothly across desktop, tablet, and mobile devices.

🌙 Dark Mode

The website supports light and dark themes.

Theme preference can be stored using:

localStorage.setItem("theme", "dark");

This allows the selected theme to remain after refreshing the page.

📱 Responsive Breakpoints

🚀 Getting Started

Clone the repository:

git clone https://github.com/yourusername/portfolio-website.git

Open the project:

cd portfolio-website

Then open:

index.html

in your browser.

No build tools or backend are required.
