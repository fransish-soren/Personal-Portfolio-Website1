# Responsive Portfolio Website

A responsive portfolio recreated from the supplied reference image using:

- HTML5
- CSS3
- Vanilla JavaScript
- Font Awesome
- Google Fonts

## Files

- `index.html` — page structure
- `style.css` — responsive design and animations
- `script.js` — mobile menu, scroll effects, reveal animation, contact form
- `assets/` — image crops taken from the supplied reference image

## Run

Open `index.html` in your browser.

## Customize

Change the name, email, text and social links inside `index.html`.
Replace the images inside `assets/` with your own project and profile images.
